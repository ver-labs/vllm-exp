Interpretation and limits:
The three modes use the same token budget, slots, KV pool, request token vectors
and open-loop arrival times. Trace runs are excluded from latency comparisons.
Prefix caching and other experimental cache/scheduling policies are disabled.
The new cap is per-request, not an aggregate prefill allowance. It does not
reorder running requests or guarantee decode-first service. Its750ms age boost
uses time since arrival and is global; it does not establish a strict wait bound.
Built-in adaptive uses threshold16 as its floor; comparing other tuned fixed
thresholds and age/cap settings would be needed before optimality claims.
TPOT is client-observed first-to-last text time/(output_tokens-1). SSE gaps
are text-chunk gaps, not exact token timing; buffering can merge tokens.
TTFT includes server waiting. Client scheduling lateness is separately saved.
One synthetic arrival trace, one model, three timing rounds: exploratory.
Text equality is reported; semantic quality was not independently evaluated.
Changes relative to earlier cache experiments cannot be inferred from these times.
28 raw files indexed with SHA256; code/plans/evidence saved locally.
No production defaults changed and no upstream PR/push/deployment performed.
