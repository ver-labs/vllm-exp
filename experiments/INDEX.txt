Experiment registry
===================

01-prefix-scheduling/ : completed; protected early-request latency, no established
                       overall advantage over FCFS. See RESULTS.txt.
02-frequency-eviction/ : targeted hot-prefix retention gain (RESULTS.txt).
                         Full concurrent A-Y: no overall throughput advantage
                         and identical cache hits (RESULTS-AY.txt).
03-nonprefix-repair/ : integrated Metal-worker comparison against native vLLM.
                      Original concurrent A-Y,3 matched pairs; actual middle-page
                      reuse, no established speedup or quality preservation.
                      See RESULTS-VLLM-AY.txt and evidence-vllm-ay/.
                      Earlier standalone diagnostic retained in RESULTS-AY.txt.
04-partial-prefix/ : exact interior-prefix indexing implemented and benchmarked.
                    GPU probe reuses31/32 tokens; original A-Y gains131 cached
                    tokens/run, small observed0.64% timing gain in3 rounds.
                    Nine candidate answers differ; semantic quality unscored.
                    See RESULTS.txt, PLAN.txt and evidence/.

05-skip-continue/ : unchunked bounded backfill implemented and benchmarked.
                     Targeted A-Y: observed3% faster completion; short-prompt
                     first text improved, long-prompt first text substantially
                     worse. Original A-Y did not activate the policy.
                     See RESULTS.txt, PLAN.txt and evidence/.

               mechanism activation across three matched profiles; batch speed

               See RESULTS.txt, PLAN.txt and evidence/.
